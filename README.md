# Signal & Noise feedback

Signal & Noise is a hobby project collecting AI news and publishing short, AI-written editions twice a day.

[Open an issue](https://github.com/phb123/signal-and-noise-feedback/issues/new) to report a wrong story, suggest a source, ask a question, or say hello. A GitHub account is required to post.

For a correction, include the story title, edition date, and a source supporting the correction.

Issues are public. Please do not post personal information, passwords, or API keys.

This repository is for feedback only. The site's source code is kept in a separate private repository.
